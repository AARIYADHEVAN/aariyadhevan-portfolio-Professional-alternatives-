# Aariyadhevan L — Cloud Engineering Portfolio

Animated, responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript. Includes the supplied profile portrait.

## Files
- `index.html` — content and page structure
- `style.css` — responsive dark/red theme, motion and reveal effects
- `script.js` — mobile menu, scroll reveal and active navigation
- `assets/profile.jpg` — optimised profile photo

## Publish on GitHub Pages
Upload the contents of this folder to the repository root, preserving the `assets` folder. In Settings → Pages choose Deploy from a branch, `main`, and `/(root)`.
